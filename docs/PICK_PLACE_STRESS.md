# 랜덤 픽앤플레이스 반복 검증

Release 시뮬레이터를 배치 모드로 실행하면 화면 렌더링과 수직 동기화를 건너뛰면서 실제 미션, 로봇 제어기, Jolt 물리, 충돌 검사, 그리퍼를 순서대로 검증한다. 제어와 물리 계산은 일반 실행과 같은 4ms 고정 간격을 사용한다.

빌드 폴더에서 다음처럼 실행한다.

```powershell
.\grasplink_simulator.exe --pick-place-stress 100 --seed 1
```

`--pick-place-stress` 뒤에는 시도 횟수를 지정한다. `--seed`는 시나리오 순서를 재현하는 32비트 정수다. 같은 빌드와 seed를 사용하면 같은 상자·목표 위치와 회전 순서를 만든다. 1,000회 검증은 횟수를 `1000`으로 바꿔 실행한다.

각 시도는 성공 여부와 실행 시간을 출력한다. 실패하면 seed, 시도 번호, 상자·목표 좌표와 회전, 미션 오류를 함께 출력한다. 시도 시간 제한은 고정 스텝 100,000회이며, 실패 뒤에는 그리퍼와 로봇을 초기 상태로 되돌리고 다음 시나리오를 진행한다. 마지막 `PickPlaceStressSummary`에는 시도 수, 성공·실패·시간 초과 수, 성공률, 총 실행 시간이 나온다.

종료 코드는 모든 시도가 성공하면 `0`, 미션 실패나 시간 초과가 있으면 `1`, 시뮬레이터 초기화 또는 실패 후 복구에 실패하면 `2`다. 따라서 자동화에서 종료 코드와 요약 줄을 함께 확인한다. 이 배치 모드는 가짜 컨트롤러를 사용하는 미션 단위 테스트나 충돌 검사를 항상 통과시키는 경로 계획 벤치마크와 달리, Viewer의 실제 미션 구성과 Jolt 충돌 검사를 실행한다.

실행 결과를 비교할 때 seed·case 수·빌드 설정을 함께 보관한다. counter 및 benchmark 결과를 해석하는 법은 [Diagnostics](DIAGNOSTICS.md)에 있고, 이 배치 실행은 그 문서의 dummy-callback planner benchmark와 범위가 다르다. Viewer의 실행 순서와 모듈 책임은 [Architecture](ARCHITECTURE.md)에 정리돼 있다.
