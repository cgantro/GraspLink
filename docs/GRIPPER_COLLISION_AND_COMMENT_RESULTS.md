# 그리퍼 충돌 및 주석 보강

이 문서는 자유공간 그리퍼 Controller 연결 전 충돌·주석 작업과 당시 테스트 결과의 기록이다. 이후 구현된 `SimGripperController`·`GripperKinematics`·`GripperTransformAdapter`와 4 ms pose/proxy 갱신 계약은 [현재 그리퍼 런타임 설계](GRIPPER_RUNTIME_DESIGN.md)를 참고한다. 아래 테스트 수와 당시 구현 상태는 과거 결과로 보존한다.

현재 Local 회전은 quaternion으로 저장하며 GLB·FK·Physics의 Euler 왕복을 제거했다. 회전 형식과 입력 계약은 [Architecture](ARCHITECTURE.md)를 참고한다. 아래 Euler 주석 검토는 당시 작업 기록이다.

## 충돌 범위

`ConfigureTwoF85Colliders`는 현재 `HCR12A_2F-85.glb`의 메시를 기준으로 본체와 6개 관절에 Kinematic 충돌 프록시 7개를 만든다.
Outer Knuckle과 Finger는 같은 관절을 따르되 각 메시의 볼록 외피를 별도 형상으로 보관한다. 두 손가락을 하나의 외피로 묶지 않는다.
형상 정점은 소유 관절의 Local 기준 m 단위이며, 프록시는 관절의 자식이므로 Fixed Update의 World 변환 갱신과 Jolt 동기화를 따라 움직인다.
그리퍼의 GLB 장착 변환은 비항등 변환이다. 테스트용 배치를 만들 때도 이를 단순한 단일 축 회전으로 가정하면 안 된다.

- [충돌 구성](../modules/simulation/src/robotics/GripperColliders.cpp)
- [Viewer 연결](../apps/viewer/ViewerApp.cpp)
- [접촉 회귀 테스트](../tests/GripperCollisionIntegrationTests.cpp)

새 테스트는 본체·양쪽 손가락의 실제 접촉 높이, 열린 간격 85 mm, 빈 간격 통과, 부모 이동과 손가락 회전 후의 접촉, 잘못된 설정의 부분 생성 방지, Scene 삭제를 검증한다.
이 작업 시점에는 Gripper 계층의 ECS 관절 자세가 기준이었고 Gripper controller, 접촉 기반 파지, 관절 토크·동역학은 구현하지 않았다.
볼록 외피는 각 메시의 오목한 공간을 메울 수 있으며, Robot/Gripper 자기 충돌은 기존 정책대로 제외한다.

## 로봇팔 충돌 단순화

삼각형 중심을 묶는 셀을 8 cm에서 16 cm로 늘렸다. 다른 부품·하위 관절·그리퍼의 형상을 합치지 않고 긴 부품의 공간 분할 수를 줄였다.
실제 GLB에 대해 축약 정점과 부피 검사를 모두 적용한 뒤 `Colliders`에 들어간 형상 수를 측정했다.

| --- | ---: | ---: |
| Link1 | 48 | 13 |
| Link2 | 68 | 28 |
| Link3 | 38 | 17 |
| Link4 | 50 | 33 |
| Link5 | 30 | 22 |
| Link6 | 8 | 8 |
| 합계 | 242 | 121 |

[회귀 테스트](../tests/RobotCollisionGeometryTests.cpp)는 실제 모델의 6개 독립 링크와 형상 수 상한을 확인한다.
셀 내부의 오목한 공간을 채우는 근사는 이전보다 커질 수 있다. GUI 표시는 설정한 형상을 화면에 투영한 윤곽이며 실제 Jolt 외피의 모든 3D 모서리를 표시하는 것은 아니다.

## 한글 Doxygen 주석

사용자의 후속 지시에 따라 [주석 기준](COMMENT_GUIDELINES.md)을 한글 Doxygen 형식으로 갱신했다.
렌더링 단계·좌표 변환·GPU 수명·FK·COM·충돌·Fixed Update·데이터 소유와 실제 미구현 범위를 설명하는 작업으로 나눴다.
Luna 작업별 파일 소유 범위를 분리하고 격리된 빌드 디렉터리를 사용한다. 주석 제거 후 C++/GLSL 토큰이 같은지도 별도로 검증한다.

27개 작업으로 C++·GLSL 98개 파일의 주석을 보강했다. 사용 가능한 동시 실행 한도에 맞춰 Luna 최대 3명이
서로 다른 파일을 맡았고, 각 작업에서 별도 빌드 디렉터리로 빌드와 테스트를 실행했다.
누락된 구현 파일도 다시 보강했다. 최종 검사에서 98개 파일 모두 변경되었으며 주석·공백을 제외한 토큰은
주석 작업 시작 시점과 같았다. 그리퍼 추가와 팔 셀 크기 변경은 이 주석 비교의 기준에 이미 반영된 기능 변경이다.

Sol 검토에서는 중복 구현·모듈 의존·소유와 해제·좌표 변환·주석 사실관계를 확인했다.
그리퍼 자세를 별도 FK 결과로 표현한 문장을 ECS 관절 계층 기준으로 바로잡고,
Euler 행렬 곱과 실제 벡터에 적용하는 회전 순서를 구분했다. UTF-8 손상·남은 영어 설명·변경 충돌도 확인했다.

## 커밋 분리

기존 감사부터 이번 후속 작업까지 기능·빌드·테스트 변경 17개, 주석 작업 27개, 문서 갱신 4개 범위로 나눈다.
제목과 변경 이유를 설명하는 본문은 한글로 작성한다. 모듈 이동·의존 방향·호출부처럼 함께 바뀌어야 하는
경계 변경은 같은 커밋에 포함하고, 그리퍼 충돌과 팔 단순화는 별도 커밋으로 기록한다.
주석 커밋은 해당 기능이 반영된 부모 버전과 비교해 실행 토큰이 같은지도 검사한다.
빌드·테스트 결과는 최종 통합 소스 기준이다.
