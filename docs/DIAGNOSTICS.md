# Diagnostics

`grasplink_diagnostics` provides asynchronous logs and semantic metrics. `Logger` copies each record into a bounded queue, and one worker thread writes JSON Lines to `logs/grasplink.jsonl` by default. Queue saturation discards new records so a control tick never waits for disk I/O; an Error log can replace a queued metric or Debug/Info log. `Flush()` waits for accepted records, and `Shutdown()` stops acceptance, drains the queue, and joins the writer. Keep the Logger alive until systems that borrow it have shut down.

Tracy is the runtime profiler. The simulator records a frame and coarse `Frame`, `FixedTick`, `RobotUpdate`, `CollisionCheck`, `PhysicsStep`, and `Render` zones. With `TRACY_ON_DEMAND` enabled, capture starts when the Tracy Profiler connects. Build the simulator, launch the Tracy Profiler application, and connect to the running simulator to inspect timings. Tracy's CMake client is pinned to release `v0.14.1`. Logger remains responsible for logs and semantic measurements such as experiment outcomes; timing samples no longer flow through Logger.

Run `build-ninja-release/grasplink_robotics_benchmarks.exe --benchmark_filter=RuntimeLinearPathStress` to stress deterministic TCP targets generated from legal joint positions through `SimRobotController`. The `/64` and `/256` cases report planner rejections, runtime faults, timeouts, and completed paths. `planner_ik_limit_stalls` counts IK attempts that stopped after a candidate step was clipped by a joint limit; it does not prove that the target or full path is unreachable, or that the robot reached a joint limit. `planner_verified_joint_limit_violations` counts explicit joint-state validation failures, while `rejections_with_known_reachable_endpoints` shows how many rejected paths had an endpoint produced by a known legal joint configuration. This check isolates path planning and controller execution; it does not include Jolt environment collisions, grasp constraints, or the full pick-and-place mission, so its completion rate is not the mission success rate.
